# Sudoku Ultimate

Игра судоку на чистом HTML/CSS/JavaScript (без сборки и зависимостей). Два режима:
классическое судоку (`index.html`) и «Супер Судоку» (`super.html`) — восемь
пересекающихся судоку-вариантов, решаемых одновременно.

## Возможности

### Обычное судоку (`index.html`)

- Генератор пазлов с гарантированным единственным решением, 4 уровня сложности.
- Заметки (карандашные пометки) в ячейках.
- Отмена хода, стирание, подсветка строки/столбца/блока и одинаковых цифр.
- Таймер, счётчик ошибок (game over после 3 ошибок), сохранение прогресса в localStorage.
- **Подсказка «недоступные клетки»**: переключатель, который при нажатии на уже поставленную цифру затемняет все клетки, куда эту цифру поставить нельзя (та же строка/столбец/блок).

### Супер Судоку (`super.html`)

Восемь 9×9 судоку-вариантов — обычное, на сложение, судоку-киллер, X-судоку,
последовательное, нестандартные блоки, смещённое и «больше/меньше» — расположены
кольцом и попарно пересекаются общими клетками (как на классической
«Super Sudoku» головоломке). Игра генерирует полностью новую раскладку
(случайные фигурные блоки и клетки-киллеры) и решение для всех восьми
судоку одновременно при каждой новой игре, с гарантией единственного решения.

- Общий движок ограничений (`js/supersudoku.js`) с bitmask-пропагацией
  (naked/hidden singles) — без неё генерация 500+ связанных клеток занимает
  минуты; с ней — миллисекунды в большинстве случаев.
- Генерация выполняется в Web Worker, чтобы не подвешивать интерфейс.
- Та же подсказка «недоступные клетки», но с учётом всех активных правил
  (диагонали, клетки-киллеры, смещённые группы и т.д.).

## Локальный запуск

Это статический сайт — просто откройте `index.html` в браузере, либо поднимите локальный сервер:

```bash
python3 -m http.server 8080
# или
npx serve .
```

## Деплой

Репозиторий настроен на автоматический деплой в GitHub Pages через GitHub Actions
(`.github/workflows/deploy.yml`) при пуше в ветку `main`. В настройках репозитория
Settings → Pages нужно один раз выбрать источник **GitHub Actions** (обычно
включается автоматически при первом запуске workflow).
