# Sudoku Ultimate

Классическая игра судоку на чистом HTML/CSS/JavaScript (без сборки и зависимостей).

## Возможности

- Генератор пазлов с гарантированным единственным решением, 4 уровня сложности.
- Заметки (карандашные пометки) в ячейках.
- Отмена хода, стирание, подсветка строки/столбца/блока и одинаковых цифр.
- Таймер, счётчик ошибок (game over после 3 ошибок), сохранение прогресса в localStorage.
- **Подсказка «недоступные клетки»**: переключатель, который при нажатии на уже поставленную цифру затемняет все клетки, куда эту цифру поставить нельзя (та же строка/столбец/блок).

## Локальный запуск

Это статический сайт — просто откройте `index.html` в браузере, либо поднимите локальный сервер:

```bash
python3 -m http.server 8080
# или
npx serve .
```

## Деплой

Репозиторий настроен на автоматический деплой в GitHub Pages через GitHub Actions
(`.github/workflows/deploy.yml`) при пуше в ветку `main`. В настройках репозитория
Settings → Pages нужно один раз выбрать источник **GitHub Actions** (обычно
включается автоматически при первом запуске workflow).
